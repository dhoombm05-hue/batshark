# batshark

سو لي صفحة رئيسية  الواجهةة و الالوان خليها مثل Apple صفحتهم الرئيسية 
انا مشروعي عن شاشات اعلانية ف يكون فيه شاشات و اعلانات عليها من هذا القبيل 
حط الشركات الي متعاقدين معهم و طريقة النمو بصورة انيميشن مع الصفحة تطلع الصور كل ماتنزل و نبذه عنا مع مشاريعنا الاخرى هذي انا بعلمك بعد ماتخلص الصفحة و حط اماكن الاشتراك او الباقات 3 باقات او تسعيرة الي تناسبك انا بعلمك بعدين كيف تكون و حط تحت اخر شي طرق التواصل واتساب و جوال فقك حاليا ICON 

اهم شي الان التصميم و الالوان شي جميل مثل واجهة ابل لكن خلها ع طريقة مشروعنا
